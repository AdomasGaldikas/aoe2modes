# AOE 2 DE Modes

An overview of game modes available in **Age of Empires II: Definitive Edition**.

---

## Single Player

### Campaign
Play through historical campaigns following famous civilizations and leaders such as Joan of Arc, Saladin, Genghis Khan, and many more. Each campaign consists of a series of scenario missions with a narrative.

### Skirmish (Standard Game)
Play a custom match against AI opponents. Configure map type, map size, starting resources, victory conditions, and difficulty.

### Scenario Editor
Build and play custom scenarios using the built-in editor. Share scenarios with the community via the Steam Workshop.

### Art of War
A set of challenge missions designed to teach and test game mechanics such as booming an economy, rushing, and defending.

### Historical Battles
Stand-alone scenarios based on famous historical engagements, separate from the full campaign series.

---

## Multiplayer

### Ranked (Ladder)
Compete in 1v1 or team games (2v2, 3v3, 4v4) on the official matchmaking ladder. Earn Elo/ranking points based on match outcomes.

#### Sub-modes
- **Random Map (RM)** – The default competitive format. Players gather resources, build up a civilization, and defeat opponents.
- **Empire Wars** – Players start in the Feudal Age with a pre-built economy, skipping the early Dark Age and speeding up the game.

### Unranked
Custom lobby games with friends or strangers without affecting ladder ranking. Supports all standard game settings.

### Co-op / Spectator
- **Spectate** – Watch ongoing multiplayer matches in real time or as a delayed stream.
- **Co-op Campaigns** – Some campaigns support cooperative play with a friend.

---

## Game Modes & Victory Conditions

| Mode | Description |
|---|---|
| **Conquest** | Defeat all enemy units and buildings. Default victory condition. |
| **Wonder** | Build a Wonder and keep it standing for a set amount of time. |
| **Relics** | Capture and hold all relics for a set amount of time. |
| **Score** | Achieve the highest score within a time limit. |
| **Time Limit** | Player with the highest score when time runs out wins. |
| **Regicide** | Protect your King unit; losing the King means losing the game. |
| **King of the Hill** | Control the central monument on the map for a set amount of time. |
| **Sudden Death** | Lose your Town Center and you lose the game. |

---

## Map Styles

- **Random Map** – Procedurally generated terrain; the standard competitive format.
- **Real World** – Maps based on real geographic locations (Arabia, Black Forest, Islands, etc.).
- **Scenario** – Hand-crafted maps used in campaigns and custom scenarios.
- **Battle Royale** – A shrinking playable area forces confrontation over time.
